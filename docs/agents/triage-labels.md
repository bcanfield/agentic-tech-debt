# Triage labels

Label vocabulary for triaging/grilling issues in this repository.
Managed by smallhours setup — edit `.smallhours.yml` `labels:` to rename,
then re-run setup; do not edit this file by hand.

- `needs-triage` — State: awaiting triage/grilling
- `needs-info` — State: blocked on missing information
- `ready-for-agent` — State: grilled + authorized; the loop's trigger
- `agent-working` — State: smallhours is implementing/fixing/resolving
- `in-review` — State: PR ready; maintainer review is the only pending act
- `ready-for-human` — State: needs a person, not the agent
- `wontfix` — State: will not be worked
- `agent` — PR: automation-owned; smallhours may modify
- `ci-failing` — PR: CI red
- `ready-to-merge` — PR: green + CLEAN, ready for review/merge
- `human-needed` — PR: automation gave up
- `bug` — Category: something is broken
- `enhancement` — Category: new capability or improvement

## System-owned states

`agent-working` and `in-review` are applied and removed by the smallhours loop only.
Never hand-apply them during triage: removing or adding one by hand is
a signal to the system (cancellation / state drift), not bookkeeping.
